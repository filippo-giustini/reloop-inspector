# Project Status

## Maturity

ReLoop Inspector is currently a **prototype concept with a complete technical and evaluation design**. The repository contains the planned OpenCV 5 workflow, architecture, acquisition protocol and criteria required to judge a future working build.

## Available evidence

| Area | Current evidence |
|---|---|
| Product concept | Problem framing, operator workflow and human-control model |
| OpenCV design | Defined quality gates, pose verification, registration and evidence-state logic |
| Architecture | Capture, orchestration, human review and proposed AWS services |
| Data protocol | Acquisition, annotation, device-level split and comparison design |
| Reproducibility | Printable A4 capture mat and inspection procedure |
| Responsible use | Explicit scope, defer path and prohibited claims |

## Not yet claimed

The team does not currently claim a completed application, deployed AWS backend, validated defect classifier, published source-code implementation or measured performance improvement. Numerical results should appear only after a frozen implementation is tested on held-out devices under the documented protocol.

## Definition of a competition-ready build

A complete build must visibly demonstrate: a real OpenCV 5 version, glare or quality rejection, a reason-specific corrective instruction, verification of the new view, multi-view evidence, human confirmation or deferral, an auditable certificate and a baseline-versus-guided evaluation with device-level denominators.

## Planned next milestone

The next milestone is a narrow proof of concept limited to one supported smartphone family and front-glass cosmetic inspection. The preferred scope is evidence acquisition and uncertainty handling rather than broad autonomous grading.
